# CMSync 2.9.0 — Minecraft 26.2

- Target Minecraft Java 26.2 with Fabric and Java 25.
- Migrate screen access, item constants, and world labels to the 26.2 APIs.
- Update required dependencies and optional integration compile targets.
- Preserve protocol v2 and `cmsync.item` v1 for older 1.21.11 and 26.1.2 peers.
- Prevent known component resets from restoring stale portable shadow values.
- Retain unknown component JSON, isolate malformed components, and bound remote
  slot allocations.
- Add game-registry codec tests and a three-version HTTP regression matrix.
- Track version changes when generating mod metadata, so cached development
  metadata cannot leak into a release build.

## Server deployment

The 26.2 client update requires no VPS redeploy or database migration. Keep
Portainer on its existing server branch and retain its settings and volumes.
The client source is published separately on `codex/minecraft-26.2`; existing
`main` and `26.1.2` branches are retained. See
[Portainer operations](../../server/PORTAINER.md#upgrading-clients-to-minecraft-262).

Install Fabric API and YACL for 26.2; Where Is It and Searchables are bundled.
Older games still require their own matching release jars. Automated checks
cannot replace the manual multiplayer and rendering checks in `docs/TESTING.md`.
